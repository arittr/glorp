Glorp Core MVP Repair Scope

Packaging is out. The spec focuses on making the existing stories true in the live product, especially watch mode.

In Scope

1. Real Usage Loop

New effective tokens should feed vitals, XP, today totals, current bucket, and recent log consistently. Daily ccusage rows should not make the live bucket lie.

2. Watch TUI Behavior

Live animation ticks, refresh without immediate double-poll, clear mixed helper diagnostics, useful blocked-but-alive states, help toggle, and compact layout behavior.

3. Terminal Design Fidelity

Pet-forward composition, seeded art colors, denser stat rows, stronger right-panel hierarchy, source rails, sparkline/log rhythm, and Tokenpet palette applied throughout.

4. Core Game Correctness

Configured cache-read weighting, daily calibration grouping, catch-up smearing, recoverable mood/decay, and evolution moments wired into watch/status.

Out of Scope

npm Release / Cross-Platform Packaging

Leave Story 010 release truth for a separate follow-up.

Prototype-Only Mechanics

No feed command, treats, ship mechanics, death/revive/graveyard, litter picker, tweak panel, stage/species overrides, or fake demo controls.

Native Log Parser / Daemon

Continue to use ccusage-family helpers and polling. No daemon or native transcript parser in this spec.

New Visual Asset System

Keep terminal ASCII as the product surface. Improve seeded color/styling and animation, but do not introduce spritesheets or pixel-art assets.
